# 🤖 Resume-Bot

Resume-Bot is a Python-based automated resume assistant designed to simplify resume-related tasks using chatbot functionality. The project helps users generate and manage resumes efficiently through an interactive bot system.

---

## ✨ Features

* 📄 Automated resume assistance
* 🤖 Chatbot-based interaction
* ⚡ Lightweight and easy to use
* 🔐 Environment variable support
* 🛠️ Simple project setup
* 🐍 Python-based implementation

---

## 🧰 Tech Stack

* Python
* Virtual Environment (venv)
* dotenv / Environment Configuration

---


## 🚀 Getting Started

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/muskan-dhawan/Resume-Bot.git
```

### 2️⃣ Navigate to Project Folder

```bash
cd Resume-Bot
```

### 3️⃣ Create Virtual Environment

```bash
python -m venv myenv
```

### 4️⃣ Activate Virtual Environment

#### Windows

```bash
myenv\Scripts\activate
```

#### Mac/Linux

```bash
source myenv/bin/activate
```

### 5️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

### 6️⃣ Run the Bot

```bash
python bot.py
```
